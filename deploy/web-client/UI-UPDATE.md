# 网页远控使用说明

## 选择设备与连接

进入“网页远控”后，左侧输入设备 ID，或从右侧当前账号的设备列表选择设备。“仅在线”、刷新与分页只影响列表，不影响手动输入。

连接需要被控设备密码，或等待对方同意。输入密码、等待批准及连接准备期间均可以点击“取消连接”。开始连接后进入远程画面，断开后恢复设备选择。

## 顶部菜单与全屏

菜单位于画面上方中间，默认自动收起；移入或点击入口展开，可固定显示。菜单、提示、文件浮窗和质量监测都叠加于画面，不预留底部工具区。全屏仍可使用菜单、断开和退出全屏。

- **显示**：选择显示器、画面缩放、画质、帧率上限、远端光标，以及质量监测和剪贴板同步。
- **键盘（键鼠设置）**：只读、滚轮反向、交换鼠标左右键、交换 Ctrl/Command，以及受支持的 Ctrl+Alt+Del、锁屏、触摸模式和软键盘。
- **文件传输**：打开页面内独立文件浮窗。
- **声音**：手动播放远端声音、静音或调节音量。
- **连接信息**：查看对端版本、显示器、加密协商及中继连接信息。

菜单内按 Escape 收起；在远程画面内按 Escape 仍交给远端。菜单和浮窗不会重建远程画面或文件会话。

## 质量监测

在“显示”中开启“显示质量监测”。右下角显示画面帧率、视频码率、网络往返、分辨率与编码，可直接关闭。

画面帧率统计网页成功绘制的帧；视频码率只统计当前屏幕收到的 VP9 编码负载，不包括音频、文件和协议开销。网络往返是被控端上一次探测的结果，不是按键到画面响应的总延迟。首个采样、无数据、切屏和恢复页面后暂时显示“—”，静止画面帧率降低属于正常情况。

监测每秒采样，关闭、页面进入后台或断开后停止轮询；不收集历史图表或传输内容。

## 剪贴板同步与直接粘贴

默认开启“剪贴板同步”。本机复制文字或 PNG 截图后，点击远程画面中的目标位置，按 Ctrl+V；Mac 使用 Cmd+V。网页发送内容并触发一次远端粘贴，不需要剪贴板面板。远端复制的文字或 PNG 在页面前台且有焦点时写入本机；浏览器拒绝时显示“点击复制”重试入口。

在“显示”里关闭同步，可停止双向文字和图片同步，并取消排队、重试和待发送粘贴。重新开启不重放旧内容。已提交给系统的浏览器剪贴板写入不能撤销。被控设备的剪贴板权限独立生效，开启本地开关不能绕过撤权。

不后台读取本机剪贴板；目前支持文字与受限 PNG，不支持任意文件或富文本。PNG 编码上限 4 MiB、边长 4096、约 419 万像素。界面“已发送粘贴操作”只表示发送完成，原生协议没有远端系统剪贴板写入完成确认；远端繁忙或目标软件不兼容时仍可能需要重试。

## 键鼠映射

“滚轮反向”同时作用于鼠标滚轮和触摸滚动。“交换鼠标左右键”同时作用于鼠标和触摸点击，中键不变。“交换 Ctrl/Command”作用于实体键、组合修饰键与软键盘；浏览器原生粘贴仍通过粘贴事件处理，不重复发送快捷键。

修改映射前释放当前按下的键和按钮。只读或被控端撤销输入权限时禁止发送输入；远端撤权期间无法保证释放已按下状态，权限恢复后由会话清理。系统和浏览器保留的快捷键仍可能被本机截获。

这些设置只保留在当前页面内，不保存到账户或浏览器存储。

## 双栏文件传输

文件浮窗左侧为本机授权目录，右侧为远端目录；使用地址栏、双击文件夹和两栏之间的箭头选择传输方向。浏览器只允许访问用户授权的本机目录，不能直接浏览全部磁盘。普通文件选择和下载放在独立备用区域。

打开文件浮窗会建立独立、加密且受文件权限限制的连接，尝试复用当前桌面认证材料完成新挑战；纯点击批准或认证失败时，仍可能需要对方再次批准或输入密码。收起浮窗保留目录和传输，不重复建立文件会话。

当前支持单文件传输、取消和同名确认，不包含递归目录、删除或重命名。缺少写入流的浏览器采用有限大小下载回退。

## 提示与验收边界

旧版加密、撤权及错误使用简短提示，点击查看详情。旧版连接仍已加密，但旧方案存在已知保密性风险；建议更新被控端后重连，实际协商结果以当前连接为准。

功能沿用现有后端配置、RustDesk 服务、证书和数据目录。构建、全量类型/协议/测试及静态资源检查由验收工作流完成。本次浏览器预览和合成数据验证不能代替被控端实际远控、剪贴板和移动真机验收。
