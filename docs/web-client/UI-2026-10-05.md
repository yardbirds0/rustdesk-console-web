# 网页远控界面修正

日期：2026-10-05。本轮依据维护者四张实测截图修正连接、文件窗口及旧版加密说明的呈现。认证、文件传输、权限、Worker 和原生协议行为不变。

## 连接
密码输入独占一排，下方“取消连接”和蓝色“连接”属于同一操作组；连接中和等待画面也提供取消。说明与操作保留24px间距，空密码连接按钮保持禁用并在深色画面上清晰可读；空密码时按Enter同样不会提交，有密码时可按Enter连接。

## 文件窗口
本机和远端均采用固定的名称/大小表头，只有条目列表滚动。长文件名截断，完整名称可通过悬停读取。普通上传和下载移到两栏外的独立“普通文件传输”区域，显示当前已加载的远端目录和所选文件；地址草稿不会改变传输目标。

已授权本机目录时普通操作默认收起；未授权、不支持或访问失败时展开。桌面视口展开该区域后，条目列表根据可用高度缩短，保留操作和状态可见；窄屏采用上下两栏，必要时滚动浮窗内容。所有普通表单控件均为36px高度、8px圆角，同级正文14px，辅助信息12px；顶部纯图标菜单为32px。

## 旧版加密
标题直接为“旧版加密”，按风险、更新远端重连、版本限制分层说明；不再展示资产摘要、核验日期或开发报告文字。警告仍根据实际协商结果显示。1.4.9仍为旧方案，只确认指定官方1.5.0 nightly构建支持新方案；nightly是开发版，不能凭版本号隐藏警告。详细技术证据仍见[安全说明](SECURITY.md)与历史验收报告。

## 检查边界
本轮串行组件回归检查连接取消/禁用态、表头独立结构、备用传输的有效目标和四locale风险说明；主控使用实际页面组件、100项长目录与合成Worker进行1366×768、1440×900、390×844的滚动、明暗主题及全屏视觉验收。浏览器预览没有进行原生远控、系统目录选择或真实文件写盘，不能代替客户端互操作验收。正式锁定依赖检查与本轮镜像编号以交付记录为准。
