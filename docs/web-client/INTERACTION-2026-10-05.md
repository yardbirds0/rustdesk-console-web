# 连接取消、双栏文件与菜单

日期：2026-10-05，Asia/Shanghai。交互实现已于 c514dff025c3 发布，锁定依赖 CI 的 51 套、344 项测试、类型检查、生产构建和容器检查通过；真实 RustDesk 客户端互操作验收仍待完成。后续界面一致性与滚动修正见[界面修正说明](UI-2026-10-05.md)。

## 连接与取消

选择设备后，密码框下方的操作组提供“取消连接”和“连接”；正在连接、认证、等待对方同意和等待画面时也能取消。取消会断开当前桌面及其文件会话，清除认证材料，迟到的连接结果不会重新打开画面。

## 文件窗口

顶部“文件传输”直接打开双栏浮窗，并开始连接文件会话。窗口收起后保留已连接会话、目录和当前传输；重新打开不会重复连接。

- 左栏是本机文件夹。点击“选择本机文件夹”调用浏览器的系统目录选择器，确认后只浏览这一授权目录及其子目录。本机地址栏使用相对于授权根的路径，不能访问根目录之外的磁盘。
- 右栏是远端目录。地址栏可以输入 Windows 盘符路径，“/”显示驱动器；上一级、刷新和双击文件夹均保留。
- 选中本机文件后点向右箭头，上传到右栏当前目录；选中远端文件后点向左箭头，保存到左栏当前目录。下载遇到同名文件先确认保留或覆盖；上传的远端重名确认沿用现有原生传输逻辑。
- 底部只显示当前传输的进度、冲突、错误和取消操作。当前传输期间不能切换目标目录。收起窗口不会取消传输，断开会话会取消并终止写流。

两栏表头固定，只有条目列表滚动。已选择本机文件夹时，普通上传/下载收在两栏外独立的“普通文件传输”区域中；未授权、不支持目录访问或访问失败时，备用操作直接展开。浏览器不支持目录授权时仍可通过普通文件选择上传和下载保存。没有流式保存能力时，下载回退上限仍是 16 MiB。支持目录授权时按块写入，不把完整文件装进内存。

目录浏览只枚举当前目录的句柄，最多 4096 项，不递归扫描；本机文件内容在选中并上传时才读取。本机授权目录句柄只保留在当前页面内存，断开桌面后清除。文件夹传输、删除、改名和断点续传没有在本轮加入。

## 文件认证

桌面使用密码连接后，文件会话尝试沿用当前会话内的认证材料。两者使用相同的随机 uint64 原生关联标识，但文件会话仍建立自己的加密连接、校验签名和文件权限，使用新的挑战响应。

认证材料只在 Worker 内存中暂存，不发给页面，不写入浏览器存储。目标、服务器配置或盐发生变化时不自动认证；错误密码或禁止密码访问时清除材料，自动尝试失败后回到明确的密码输入或对方批准。

等待期间默认显示连接状态，可按需点击“使用密码”；真正认证失败才自动展开密码输入。桌面通过对方点击批准不意味着已证明密码正确，不能因此代替文件授权。文件登录成功后清除其认证副本；文件撤权、取消或断开会使正在派生的旧材料失效。

## 顶部菜单

显示菜单提供适应窗口、原始尺寸、本地缩放、画质、帧率、远端光标、刷新画面和显示器选择。画质、帧率和光标设置使用现有原生协议；刷新和显示器切换沿用已实现命令。

键盘菜单提供只读模式、常用键、修饰键、软键盘和显式文本输入。Windows 的锁屏以及远端报告支持时的 Ctrl+Alt+Del 使用原生控制消息，不模拟本机快捷键。只读模式同时在页面、Worker 和会话输入处阻止操作；关闭只读仍须遵守远端当前输入权限。

声音、文件、全屏和断开入口保留。信息菜单显示实际设备 ID、客户端版本、当前画面尺寸、加密协商和中继方式，不虚构延迟、帧率或网络测速结果。

## 验证与待验

实施阶段串行运行八套定向测试，135 项通过；特殊键和 uint64 修正后四套受影响测试 101 项通过，认证表单调整后页面 40 项通过。独立审查新增两项 H2 派生与错误/人工批准竞态用例，以及一项文件撤权后的同代次迟到事件用例，并修复后者先红后绿复现的缺陷。审查后的最终页面测试 41 项通过；认证、Worker、本机目录和文件传输审查四套测试 70 项通过。上述批次数字有重叠，不能相加作为独立用例总数。`--detectOpenHandles` 正常退出，没有报告遗留句柄。页面测试仍有既有剪贴板异步状态的 React act 提示。

浏览器分批完成 27 项不同命名的主路径检查，以及自修复后的 8 项视觉/交互细节检查：取消连接、Long 加载、双栏路径、菜单、全屏、390 像素暗色布局、空目录居中、备用操作展开与窄屏传输箭头方向。检查使用实际页面组件、合成 Worker 和合成目录句柄；没有验证系统目录选择器、真实文件写盘或原生设备认证，不能据此写成真实客户端验收通过。

独立审查最终对 18 个修改/新增 TypeScript 文件运行 Biome lint，没有错误；另有非阻塞风格建议。git diff --check 通过。本机完整 TypeScript 检查仍因复用的旧 AntD/Umi 依赖和生成导出差异失败；Web Client 范围只剩既有 Umi 导出缺失，需由锁定依赖 CI 完成正式类型检查和生产构建。本轮没有安装依赖、生产构建或大文件压力测试。

真实客户端待验：Windows 密码连接后的文件自动认证、纯点击批准及错误密码回退、远端撤销文件/输入权限、双向单文件传输和覆盖、取消写流、画质/帧率/光标、锁屏和 Ctrl+Alt+Del。组件合成协议回归不能替代这些互操作验收。

本轮没有补齐后台逐连接授权网关、用户绑定审计或后台撤权联动，也没有新增 P2P、WebRTC 或信令服务。既有权限与审计边界继续适用。
